# jewerly_php
Jewelry Workshop Website — php version

An educational web development project for a fictional jewelry brand, built using PHP, HTML, CSS, JavaScript and MySQL.
The project extends the front-end website with server-side functionality and database interactions. The jewelry brand and business concept are fictional and do not represent a real company.

Features
* User registration and authentication
* Form processing and server-side validation
* MySQL database interactions using PDO
* Session and cookie handling
* CSRF token implementation
* Admin panel for managing records
* Basic API functionality

Technologies
* PHP
* MySQL
* PDO
* HTML5
* CSS3
* JavaScript

Project structure
* index.php, front.php — main page and form processing
* form.php, login.php — registration and authentication
* admin.php — administrative interface
* db.php, settings.php — database connection and helper functions
* api.php — API functionality
* try_page.tpl.php — page template
* try.css — website styles

Setup
The project requires a PHP environment and a MySQL database.
Database connection settings must be configured locally before running the application. The repository contains placeholder credentials rather than real access details.

Notes
This is an educational project and is not a deployed or production-ready online store. Some functionality may require additional configuration or further development.
